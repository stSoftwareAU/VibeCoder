# 🎨 Vibe Coder social media images

Transparent, outlined artwork of the Vibe Coder mascot: a
smiling purple robot between two code brackets, in a vibrant purple-led
palette that reads on both light and dark backgrounds. Each PNG ships with its
editable SVG source beside it. Logo artwork only — no name, tagline or feature
text — so the images work wherever the surrounding page supplies the words.

| Asset | Size | Use |
|---|---|---|
| [`vibe-coder-social-preview.png`](vibe-coder-social-preview.png) ([SVG](vibe-coder-social-preview.svg)) | 1280×640 | GitHub social preview (repository settings → Social preview) |
| [`vibe-coder-avatar.png`](vibe-coder-avatar.png) ([SVG](vibe-coder-avatar.svg)) | 1024×1024 | Square logo / avatar (org and app icons, package READMEs) |
| [`vibe-coder-banner.png`](vibe-coder-banner.png) ([SVG](vibe-coder-banner.svg)) | 1500×500 | Wide banner (X / LinkedIn headers, README masthead) |

## Where they are used

- [`README.md`](../../README.md) — the banner as the masthead.
- [`worker/deno/README.md`](../../worker/deno/README.md) — the avatar for the
  worker package.
- [`docs/workflows/README.md`](../workflows/README.md) — the social preview at
  the top of the user manual.
- GitHub repository social preview — upload `vibe-coder-social-preview.png`
  under *Settings → General → Social preview*.

## Guidelines

- Keep the transparent background; do not add a solid fill.
- Do not stretch: scale proportionally, or crop the banner's outer sparkles.
- Edit the SVG, then re-export the PNG at the size above; commit both.
