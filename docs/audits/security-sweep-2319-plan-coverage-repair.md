## `worker/deno/lib/plan_coverage_repair.ts`

When the plan-coverage gate fails, the module reads the planning parent and the
sub-issues the run published, asks the planning-phase model to draft the
`## Plan Coverage` table, posts the table on the parent, and re-runs the real
gate. It is the coverage counterpart of `failure_detection_repair.ts` and reuses
its runner type, invocation record and cost estimate.

| Input                       | Source                                                                                | How it is handled                                                                                                                                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| parent title and body       | fetched back from GitHub — **untrusted**: anyone with write access can have edited it | scrubbed with `sanitiseDelimiterPatterns`, placed inside a sized code fence between this run's randomised boundary markers, covered by `buildBoundaryIntegrityInstruction`                                                               |
| sub-issue titles and bodies | fetched back from GitHub — **untrusted** for the same reason                          | same handling; each body is cut to 4,000 characters before it reaches the prompt, so the prompt is bounded by the number of sub-issues the run itself published                                                                          |
| `subIssueNumbers`           | the run's own published set                                                           | passed as one argv element each to `gh issue view`; never interpolated into a shell                                                                                                                                                      |
| the model's draft           | **untrusted** — it is conditioned on the text above                                   | never posted. `extractCoverageTable` parses rows out of it (bounded by the shared 64 KiB table-scan cap) and the comment is **rebuilt from those rows alone**, so prose, headings, HTML and markers around the table cannot reach GitHub |
| each rebuilt cell           | the parsed rows                                                                       | whitespace collapsed to single spaces (a cell cannot start a new line, heading or fence), `\|` replaced so a cell cannot add a column, and `@` followed by a zero-width space so a cell cannot notify a user or team                     |
| `deadlineMs`                | the dispatcher's own watchdog budget                                                  | compared with the clock; a repair that cannot fit is not started                                                                                                                                                                         |

| Property                     | Result                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| spawn chokepoints            | none of its own. GitHub reads go through the injected `ghCommandFn`, the comment through the injected `postComment`, the model through the injected `runClaude` — all three are the planning processor's existing chokepoints                                                                                                                                                                                                                 |
| prompt injection             | the untrusted text is fenced and the task instruction follows the closing marker. A successful injection can at worst influence **which rows the table carries** — see the next row for why that is bounded                                                                                                                                                                                                                                   |
| can the repair forge a pass? | the verdict returned is never the draft's: it is `runPlanCoverageGate` re-run against the parent, author check included. A draft can only pass by citing a sub-issue for every ask — the same power the publish turn's own summary comment has always had, under the same gate. It adds no new way through. The prompt tells the model to write `None` for an uncovered ask, and such a row fails the re-gate and escalates exactly as before |
| what is written              | one comment on the planning parent, as the fleet identity, containing a fixed heading, a fixed provenance line and the rebuilt table. Nothing is edited, labelled or closed by this module                                                                                                                                                                                                                                                    |
| network                      | none beyond the injected `gh` and model calls                                                                                                                                                                                                                                                                                                                                                                                                 |
| regex safety                 | three linear single-character-class replacements in `cell`; table parsing is the shared, capped `findMarkdownTable`                                                                                                                                                                                                                                                                                                                           |
| filesystem                   | none                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| secret surface               | holds no credential; log lines carry the repo, the issue number, counts and an error message                                                                                                                                                                                                                                                                                                                                                  |
| fail direction               | fail-closed towards the old behaviour: an unreadable parent, no readable sub-issue, a model failure, a timeout, a draft with no table, a failed post and an exhausted budget each return the **original failing verdict untouched**, so the caller escalates as it did before this module existed                                                                                                                                             |
| blast radius                 | reached only when the gate has already failed. A passing plan never enters it                                                                                                                                                                                                                                                                                                                                                                 |
