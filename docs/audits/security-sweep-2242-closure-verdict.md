# Security sweep — the closure verdict render (`closure_verdict*.ts`)

**Issue:** [#2242](https://github.com/stSoftwareAU/VibeCoder/issues/2242) (chunk
top-up-2242) · **Parent:** #1209

This is the written record for the two modules that entered `worker/deno/lib/`
under #2242:

- `worker/deno/lib/closure_verdict.ts` — pure parse, coverage and render.
- `worker/deno/lib/closure_verdict_recovery.ts` — the constrained question, the
  single re-ask, and the summary write.

## Why a new slice rather than a line in an old one

Appending a module to a slice whose sweep ran before it existed is the cheapest
way to make `diffCoverage` green and a false record. Both modules are claimed by
**top-up-2242**, and this file is the reading of them.

## `worker/deno/lib/closure_verdict.ts`

Pure: no spawn, no filesystem, no network, no environment read. It parses a
model-authored JSON block and renders two markdown blocks from it.

| Input                                           | Source                                        | How it is handled                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| the agent's reply                               | the model, steered by an untrusted issue body | scanned only within `MAX_VERDICT_CHARS` (100k); the **last** `<closure_verdict>` block wins, so an example quoted from the prompt cannot displace the answer; a code fence is stripped line-wise; `JSON.parse` failure is returned as an error, never a default                                                                                                        |
| `criterion` / `finding` / `evidence` / `reason` | the model                                     | `sanitiseField`: newlines collapsed, HTML-comment markers removed, the `evidence:` / `reason:` / `reviewer:` label keywords removed **together with any letters glued in front of them** (the validators' own patterns are unanchored, so `Xevidence:` would otherwise read as a filled field), markdown emphasis/heading/pipe characters removed, capped at 300 chars |
| entry counts                                    | the model                                     | capped at `MAX_ENTRIES` (100) per axis; a truncation is recorded in `dropped`, so it surfaces as a coverage shortfall rather than vanishing                                                                                                                                                                                                                            |

| Property                       | Result                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| no shell, no argv construction | none — the module spawns nothing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| environment                    | untouched                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| filesystem                     | none                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| network                        | none                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| regex safety                   | every pattern is bounded and non-ambiguous. `sanitiseField`'s keyword scrub uses a bounded `[A-Za-z]{0,32}` prefix over a literal alternation. The section-removal heading test trims the line and strips a trailing colon **before** matching, so the gates' own `\s*:?\s*$` tail — two adjacent unbounded whitespace quantifiers, ~16× per 4× input on a hostile line — is not reproduced here; `closure_verdict_test.ts` pins the shape with `assertLinearGrowth`, and candidate lines over 200 chars are refused outright |
| secret surface                 | no credential is read, logged or interpolated                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| resource bounds                | 100k scan cap, 100 entries per axis, 300 chars per field                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| fail direction                 | fail-loud: a missing block, an unclosed block, non-JSON, or a `criteria` that is not an array each return an error. An entry that cannot be read is named in `dropped` and becomes a coverage shortfall — nothing is silently kept or silently cut, and no status is ever invented                                                                                                                                                                                                                                            |

No finding. The deliberate trust decision is that the **content** of every entry
is the model's. The shape is not: headings, provenance markers, the entry
grammar and the `reviewer:` field are worker-rendered, and the `reviewer:` value
is the model's own status, so a rendered entry cannot record a departure that
was never made.

## `worker/deno/lib/closure_verdict_recovery.ts`

One prompt builder, one invocation wrapper, one orchestrator. The model
invocation goes through `deps.claude.runClaudeWithRetry` (swept under 12a/12b);
the only direct I/O is reading the run's own PR summary and writing it back.

| Input                           | Source                                                                   | How it is handled                                                                                                                                                                                                                                         |
| ------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| the issue's acceptance criteria | the issue body — attacker-supplied                                       | fenced with `fenceUntrustedIssueText`, whose CSPRNG nonce an attacker cannot guess and whose scrub neutralises forged delimiters and HTML comments; `closure_verdict_prompt_test.ts` pins that a forged closing boundary leaves exactly one real boundary |
| the gates' problem lines        | the worker's own gate comment builders, quoting the branch's own summary | interpolated as prompt text, the same trust decision `summary_rule_gate_retry.ts` records for the replayed gate comment                                                                                                                                   |
| the agent's reply               | the model                                                                | parsed by `parseClosureVerdict` above; an unreadable reply is logged and treated as no verdict                                                                                                                                                            |
| `state.repoPath`, `issueNumber` | the worker's own clone path and the claim it holds                       | the summary path is `loadPrSummary`'s own source path, or the canonical `docs/archive/pr-summaries/pr-summary-<issue>.md` built from the integer issue number — no model-supplied path ever reaches the filesystem                                        |

| Property                       | Result                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| no shell, no argv construction | none: the only child process is the one `runClaudeWithRetry` spawns through its existing boundary                                                                                                                                                                                                                                                                                                         |
| environment                    | untouched                                                                                                                                                                                                                                                                                                                                                                                                 |
| filesystem                     | one read (through `loadPrSummary`) and one write, both under `state.repoPath` at a worker-derived relative path; `Deno.mkdir` is recursive on the summary's own directory                                                                                                                                                                                                                                 |
| network                        | none                                                                                                                                                                                                                                                                                                                                                                                                      |
| regex safety                   | none used directly; the validators it calls own theirs                                                                                                                                                                                                                                                                                                                                                    |
| secret surface                 | logs carry the repo, the issue number, the gate problems and the shortfall lines — no credential                                                                                                                                                                                                                                                                                                          |
| resource bounds                | at most **two** model invocations per recovery, each bounded by the run's `claudeTimeout` / `claudeKillAfter` / `maxRateLimitRetries`                                                                                                                                                                                                                                                                     |
| fail direction                 | fail-loud: `buildClosureVerdictPrompt` throws on zero criteria rather than asking an unanswerable question; a summary that cannot be read, a verdict that cannot be parsed and a launch that fails each leave the summary untouched and return `unavailable`, so the gate block stands exactly as it did before. A rendered block that still fails the gates is logged as such — never reported as a pass |

No finding.
